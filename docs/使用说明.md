# 桌面切屏/课件翻页助手 1.3.3

退出旧版，解压便携包，双击 `DesktopSwitcher.exe`。请将 `DesktopSwitcher.exe.config` 与程序保存在同一文件夹，无需安装。

## 退出、重复打开和删除

选择“退出程序”会停止检测和等待操作、关闭提示和菜单，清理托盘及图标，并结束本工具自身进程。若 UI 或清理阻塞，约 2.5 秒后由独立退出兜底结束本进程，不影响课件或其他应用。课件翻页未放映时只是隐藏悬浮按钮，程序仍在运行；需要删除或更新时应先退出。

再次双击已经运行的程序，会显示“程序已在运行”的状态窗口，可选择桌面切屏、课件翻页或退出。不会额外留下另一个隐藏实例。

若 Windows 明确提示“应用程序控制策略已阻止”，这是系统启动拦截，与文件占用不同，退出流程修复不会修改该策略。

## 首次使用

尚未完成首次选择的用户会显示模式选择：

- **桌面切屏**：左右按钮切换虚拟桌面，到最右侧时新建并进入。
- **课件翻页**：只有前台 PowerPoint/WPS 正在全屏放映时显示，左右按钮用于翻页或执行原生动画步骤。

选择课件翻页后会询问是否允许程序随 Windows 登录自动启动。选择“允许开机启动”才开启；选择“暂不开启”仍可正常使用，不会反复询问。以后可在右键或托盘菜单中手动开关“开机启动”。这只设置当前用户登录启动，不需要管理员权限。

模式选择会保存，下次不再显示首次提示。从没有首次提示记录的版本升级时会询问一次；1.3.0 已完成选择的用户不会重复询问，原位置及“不再提醒”选择保留。关闭首次提示而未选择模式时退出程序，下次运行仍可选择。

## 两种模式

右键悬浮按钮或任务栏托盘图标，选择“桌面切屏”或“课件翻页”，重启后继续沿用。

桌面切屏模式中，悬浮按钮保持显示：左箭头切换到左侧桌面，在第一个桌面时不动；右箭头切换到右侧桌面，到最后一个桌面时新建并进入。即使正在放映，该模式仍执行切屏。

课件翻页未放映时只保留托盘。连续两次确认前台 PowerPoint/WPS 的全屏放映后显示翻页按钮；结束、关闭、离开放映或切到其他软件时隐藏；返回放映后重新显示。课件翻页不会发送桌面切换或新建桌面指令。

编辑窗口、演讲者视图、普通最大化、浏览器和视频全屏不会触发。检测仍采用 150 毫秒轮询。不同 WPS 版本可能改变窗口特征，无法确认时保持隐藏。

## 聚光灯引导

放映时压暗所在屏幕背景，圈出翻页按钮，并提示“在这里也可以翻页”。

引导**不再自动倒计时消失**。点击按钮区域以外的屏幕位置可关闭本次引导，点击提示卡的空白或文字也可关闭；下一次重新进入放映仍可提醒。点击亮出的翻页按钮不会关闭引导。

点击“不再提醒”立即关闭并保存选择，以后不再弹出，翻页继续工作。旧版已保存的“不再提醒”继续沿用。

放映结束、离开放映窗口或切换运行模式时，引导与课件界面一起隐藏。引导不主动取得键盘焦点。

## 自由拖动与贴边隐藏

可以按住左右箭头、中间竖线或底座空白处拖动。轻点箭头执行操作；按住移动则拖动，松开不翻页、不切屏。没有网格或分段位置限制，位置按实际屏幕像素保存。

只有可见底座真正接触屏幕左边或右边时才吸附，容许最多 2 个物理像素的边界误差。与边缘间隔 3 个物理像素以上时不会吸附，可自由停放。透明阴影边距不占用可见控件的拖动范围。

吸附后，鼠标离开约 0.9 秒开始收起，只留窄边缘；鼠标碰到边缘即展开。收起和展开使用约 200 毫秒滑动与淡入淡出，快速反向从当前动画位置继续，不调整窗口大小。菜单打开、操作、拖动或显示聚光灯时保持展开。

**课件翻页默认关闭贴边自动隐藏**。桌面切屏和课件翻页分别记住“贴边自动隐藏”及吸附侧，桌面模式的旧吸附选择不会让课件翻页自动收起。需要时可在课件翻页下自行勾选；取消后保持展开。

将控件拖回屏幕中间即可解除吸附。“恢复右下角位置”会解除当前模式吸附，回到主屏默认位置。

## 透明沉浸

右键或托盘勾选“透明沉浸”，控件只显示黑色左箭头、右箭头和竖线，去掉可见背景、边框及阴影；悬停也不会出现背景框。每侧操作区为 43×42 个逻辑像素，箭头周围的透明空白也可点击；图标大小保持不变。中间竖线及按钮区域仍可拖动。

取消勾选恢复半透明深色底座。旧版“透明模式”的选择继续沿用为透明沉浸。贴边收起时窄条保持可见，便于找回控件。

## 右键与托盘

菜单提供桌面切屏、课件翻页、透明沉浸、贴边自动隐藏、恢复右下角位置、开机启动、退出程序。没有选择命令时，点击菜单外或切换到其他软件即收起菜单，关闭后不再捕获鼠标。

托盘图标可能收在任务栏的隐藏图标区域。课件界面隐藏时，可从托盘切换模式或退出；双击托盘图标恢复默认位置。

默认底座 96×44 个逻辑像素，距主屏工作区右边、下边各 20 个逻辑像素，避开任务栏。放映时临时跟随前台放映所在显示器，返回桌面模式沿用位置。显示器断开或布局改变后会调整到可见区域。

升级或移动程序目录后，如要开机启动，请在新版重新勾选以更新路径；首次课件翻页允许启动时也会写入当前程序路径。拒绝本次询问不会删除之前已存在的其他版本启动项。

配置位于 `%LOCALAPPDATA%\DesktopSwitcher\settings.xml`，日志在同目录 `diagnostics.log`。退出不会删除虚拟桌面。

## 输入与兼容

先松开 Ctrl、Win、Alt 和 Shift。翻页仍有 120 毫秒防连击，发送前再次确认模式、目标身份和前台；模式变化时取消等待中的旧操作，不改成其他功能。鼠标展开后的短暂保护可避免动画尚未结束时误触。

桌面模式保留首次初始化修复：系统还没有额外虚拟桌面时，左侧不动，右侧新建并进入。数据缺失、损坏或无法可靠判断时停止自动新建。Windows 的桌面登记信息并非稳定公开接口，后续格式变化应停止操作并提示。

需要 Windows 10/11 和 .NET Framework 4.8 或兼容版本。系统安全界面、独占全屏、远程桌面和管理员应用可能影响覆盖或输入。不同版本课件软件及多屏现场验证限制详见 `验证记录.md`。

## 构建与打包

在项目根目录运行：

```powershell
.\Build.ps1
.\build\qa\Tests.exe
.\build\qa\Tests.exe --widget-probe
.\build\qa\Tests.exe --lifecycle-probe
.\Build.ps1 -OutputDirectory releases\1.3.3\portable
.\Package.ps1
```

交付在 `releases/1.3.3/`，源码、测试及文档分别在 `src/`、`tests/`、`docs/`。历史版本保留。构建使用本机已有微软签名编译器，不下载依赖；构建清单记录来源与哈希，打包检查版本和完整性。

诊断命令：`DesktopSwitcher.exe --exit` 请求当前实例退出；`--data-dir <绝对目录>` 可使用独立配置和日志，与正常配置隔离。验证使用了相同的交付 EXE，没有使用测试程序替代。
